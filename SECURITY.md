# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, using GitHub's private vulnerability reporting (GitHub Security Advisories):

1. Go to the [Security tab](https://github.com/markc647/fernledger/security) of this repository.
2. Choose **Report a vulnerability**, or use [this direct link](https://github.com/markc647/fernledger/security/advisories/new).
3. Describe what you found and how to reproduce it.

**Please don't open a public issue or pull request for a vulnerability.** Don't include real bank data or real credentials in a report.

Security fixes ship as patch releases, with a GitHub Security Advisory. To hear about them, **Watch → Releases** on this repository and subscribe to its security advisories.

## What's in scope

Vulnerabilities in the Fernledger code in this repository. Each Deployer runs their own copy in their own Cloudflare account, and the project's authors never see their data. If you think your own deployment has been breached, follow the breach checklist in [docs/security.md](docs/security.md#if-something-goes-wrong).
